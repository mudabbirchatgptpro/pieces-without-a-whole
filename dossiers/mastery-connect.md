# Dossier: Mastery Connect (Instructure)
Frame stratum: 5.4   Evidence collected: 2026-10-24   Collector: stratum-5.4 agent D
Frame source: Instructure, The Edtech Top 40: K-12 Edtech Engagement During the 2025-26 School Year, entry 'Mastery Connect' (list is alphabetical, unranked)

## Identity
- "Mastery Connect is the K–12 digital assessment management system that allows teachers to efficiently and effectively determine what a student knows and does not know based on the core standards." (https://community.instructure.com/en/kb/articles/663316-what-is-mastery-connect, accessed 2026-10-24)
- "Mastery Connect is an assessment management system and curriculum platform designed to show learning in an intuitive, visual way." (https://www.instructure.com/resources/blog/intro-mastery-connect-instructures-ams, accessed 2026-10-24)
- "MasteryConnect is a standards-based assessment platform: teachers deliver assessments, and the platform tracks each student's mastery of the standards those assessments measure." (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
- "Mastery Connect is used by educators to assess their students and plan curriculum." (https://www.instructure.com/policies/product-privacy-policy, accessed 2026-10-24)
- Ownership: the product appears in Instructure's product privacy notice under the heading "Mastery" alongside "Mastery Connect, Mastery Item Bank, Mastery Item Bank Supplemental, Mastery College Prep Assessments, Mastery View Predictive Assessments, Mastery Predictive Assessments, Mastery View Formative Assessments" (https://www.instructure.com/policies/product-privacy-policy, accessed 2026-10-24)
- Self-description as "operating system"/"OS": none found on the pages listed in this dossier.

## E1 Sequencing / scheduling evidence
- "When an assessment is added to your mastery tracker, a Canvas assignment is created automatically." (https://community.instructure.com/en/discussion/546971/best-practices-for-mastery-connect-canvas-integration, accessed 2026-10-24)
- "Creating a Mastery Connect assessment from your tracker in Canvas automatically creates a Canvas assignment." (https://community.instructure.com/en/kb/articles/662061-how-do-i-use-a-mastery-connect-tracker-in-a-canvas-course, accessed 2026-10-24)
- Curriculum map: "organises Objectives and Materials into a planned sequence, typically a scope-and-sequence for a course." (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
- Pathway: "groups Objectives for a subject into a progression." (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
- "Note: For consistency in trackers, admins, and others can create trackers according to a curriculum map." (https://community.instructure.com/en/kb/articles/663316-what-is-mastery-connect, accessed 2026-10-24)
Automatic selection of a learner's next activity (adaptive path or recommendation engine), within Mastery Connect or across other vendors' tools: none found on the pages listed in this dossier.

## E2 Interfaces evidence
Public REST API (read-only):
- "The MasteryConnect REST API (v2) gives a district programmatic, read-only access to its own assessment data" (https://developerdocs.instructure.com/services/mastery-connect.md, accessed 2026-10-24)
- "There is no endpoint that creates, updates or deletes anything, and no scope that grants write access." (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
- "It is built for extracting data into your own systems, not for driving MasteryConnect from outside." (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
- "The API must be turned on for your district before any credential will work." (https://developerdocs.instructure.com/services/mastery-connect.md, accessed 2026-10-24)
- "This release introduces the modernized V2 public API and moves authentication from OAuth 1.0 to OAuth 2.0." (https://community.instructure.com/en/discussion/667245/district-data-access-for-mastery-connect-rest-api-q4-2026-feature-overview, accessed 2026-10-24)
Canvas LTI and grade passback:
- "In order to link a mastery tracker to your Canvas course, your Instructure Customer Success Manager (CSM) must first set up an LTI connection between your instances of Canvas and Mastery Connect." (https://community.instructure.com/en/kb/articles/662061-how-do-i-use-a-mastery-connect-tracker-in-a-canvas-course, accessed 2026-10-24)
- "When a student completes the linked assignment, the assignment score displays in the Canvas gradebook." (https://community.instructure.com/en/kb/articles/662061-how-do-i-use-a-mastery-connect-tracker-in-a-canvas-course, accessed 2026-10-24)
- "A single sign-on and automatic data passback let you launch Mastery Connect assessments directly from the Canvas LMS." (https://community.instructure.com/en/kb/articles/663316-what-is-mastery-connect, accessed 2026-10-24)
- "As Mastery Connect is a third-party tool, you can reach the Inline Editor by enabling the Third party tool frame, once you have navigated to Mastery Connect inside Canvas." (https://community.instructure.com/en/kb/articles/662370-how-do-i-use-the-legacy-impact-integration-in-mastery-connect-lti-for-canvas, accessed 2026-10-24)
Ed-Fi, rostering, SSO:
- "Mastery Connect supports data connections using Secure File Transfer Protocol (SFTP) and via Ed-Fi v2.5.0." (https://community.instructure.com/en/kb/articles/662295-how-do-i-add-a-managed-data-connection-via-ed-fi-api-as-a-mastery-connect-admin, accessed 2026-10-24)
- "As a Mastery Connect admin, you can export assessment reports to your connected data servers." (https://community.instructure.com/en/kb/articles/662290-how-do-i-export-assessment-data-via-ed-fi-api-as-a-mastery-connect-admin, accessed 2026-10-24)
- "You can also sign in to Mastery Connect using a Mastery Connect account, a Google account, or a Classlink account." (https://community.instructure.com/en/kb/articles/663321-how-do-i-log-in-to-mastery-connect-with-a-clever-account, accessed 2026-10-24)
- "From a Clever/Classlink integration to a direct integration with the SIS" (https://community.instructure.com/en/kb/articles/664251-sis-conversion-faq, accessed 2026-10-24)
Vendor statements of 1EdTech certification, OneRoster, Caliper, QTI, CASE or LTI Advantage service names for Mastery Connect: none found on the pages listed in this dossier.

## E3 Learner model evidence
- "Mastery results are displayed by standard, so while students will still get an overall percentage on any assessment taken, the focus is on the mastery level of the specific standards." (https://community.instructure.com/en/kb/articles/663316-what-is-mastery-connect, accessed 2026-10-24)
- "Proficiency calculations determine how scores are calculated as well as the interactions between scores." (https://community.instructure.com/en/kb/articles/662287-what-are-the-available-proficiency-calculation-settings-in-mastery-connect, accessed 2026-10-24)
- "Some calculation methods also include default cut scores and decay rates." (https://community.instructure.com/en/kb/articles/662287-what-are-the-available-proficiency-calculation-settings-in-mastery-connect, accessed 2026-10-24)
- "A Classroom is the MasteryConnect tracker a teacher assesses against." (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
- "Objectives are the learning targets that assessments measure and mastery is reported against." (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
Inputs from other tools:
- Canvas quizzes (Instructure): "you can convert Canvas quizzes into Mastery Connect assessments" (https://community.instructure.com/en/kb/articles/663316-what-is-mastery-connect, accessed 2026-10-24)
- "If you link an existing tracker, any previously added students display in the Students column [1]." (https://community.instructure.com/en/kb/articles/662061-how-do-i-use-a-mastery-connect-tracker-in-a-canvas-course, accessed 2026-10-24)
Independent vendors' tools writing mastery or scores into Mastery Connect trackers: none found on the pages listed in this dossier (the REST API is documented as read-only, quoted under E2).

## E4 Data protection evidence
API credential scopes:
- "Every request is authenticated with an OAuth 2.0 Bearer token and scoped to the single district that issued the credential." (https://developerdocs.instructure.com/services/mastery-connect.md, accessed 2026-10-24)
- "Each endpoint requires one scope. All scopes are read-only." (https://developerdocs.instructure.com/services/mastery-connect/authentication.md, accessed 2026-10-24)
- "Request the narrowest set that does the job." (https://developerdocs.instructure.com/services/mastery-connect/authentication.md, accessed 2026-10-24)
- "Some data is withheld regardless of the scopes you hold:" (https://developerdocs.instructure.com/services/mastery-connect/key-concepts.md, accessed 2026-10-24)
- Scope table rows include "`assessments:read` | Assessments" and "`reports:read` | Reports" (https://developerdocs.instructure.com/services/mastery-connect/authentication.md, accessed 2026-10-24)
District-level enablement and privacy policy:
- "Make sure to alert your Instructure CSM if you would like to enable the Impact widget in Mastery Connect." (https://community.instructure.com/en/kb/articles/662370-how-do-i-use-the-legacy-impact-integration-in-mastery-connect-lti-for-canvas, accessed 2026-10-24)
- Data categories listed include "date of birth (Portfolium, Mastery Connect, and Elevate only)" (https://www.instructure.com/policies/product-privacy-policy, accessed 2026-10-24)
Per-tool permission controls for third-party tools that run inside Mastery Connect (for example Desmos or LockDown Browser, see E5): none found on the pages listed in this dossier.

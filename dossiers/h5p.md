## E3 Learner model evidence
- "H5P.com doesn't store xAPI statements, it's only forwarded to the LRS." (https://help.h5p.com/hc/en-us/articles/15503023303837-LRS-Integration, accessed 2026-10-24)
- "Since H5P is a plugin for publishing tools H5P does not include its own LRS integration." (https://h5p.org/documentation/x-api, accessed 2026-10-24)
- "The vast majority of H5P content types send answered or completed statements with score and the user's answers when the user completes a task." (https://h5p.org/documentation/x-api, accessed 2026-10-24)
- "The service data may include the content that you provided us with as an author, and your interaction results as a user: start time, finish time and score." (https://help.h5p.com/hc/en-us/articles/23070853946141-Privacy-Policy, accessed 2026-10-24)
- "H5P.com also provides analytics accessible from within Canvas so that teachers may see what the learners answered to the different H5P questions." (https://h5p.org/documentation/for-authors/h5p-for-canvas, accessed 2026-10-24)
No page found describing a mastery, skill or knowledge-state model, or other vendors' tools writing into one.

## E4 Data protection evidence
Per-organization LRS controls (xAPI forwarding):
- "Since the LRS integration can involve sending sensitive student data to an endpoint, this feature is disabled by default, and one of the organization's administrators must request activation directly to H5P.com." (https://help.h5p.com/hc/en-us/articles/15503023303837-LRS-Integration, accessed 2026-10-24)
- "Decide your "LRS anonymity" by choosing one of these options: Send email, Send LTI user ID, or Anonymous. And save the changes" (https://help.h5p.com/hc/en-us/articles/15503023303837-LRS-Integration, accessed 2026-10-24)
Report-visibility permissions by role:
- "To be FERPA-compliant, h5p.com offers the possibility to control who can view the drill-down reports for an H5P. This setting is found under Manage Organization->Settings->Permissions." - "Course Teacher: If this is enabled, any course instructor viewing the H5P through LTI, will be able to view the reports." (https://help.h5p.com/hc/en-us/articles/7506469641757-Can-I-decide-who-sees-the-student-drill-down-reports, accessed 2026-10-24)

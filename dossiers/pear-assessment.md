## E3 Learner model evidence
Standards mastery model:
- "Pear Assessment translates student performance in a specific standard to a standards-based grade. This is done using a customizable standards-based performance band and a standards proficiency calculation method." (https://docs.goguardian.com/products/pear-assessment/learn-how-supports-standards-based-grading.md, accessed 2026-10-24)
- "Pear Assessment now Calculates Mastery Score for Standard by Combining Scores from Prior Assessments." (https://docs.goguardian.com/products/pear-assessment/learn-how-supports-standards-based-grading.md, accessed 2026-10-24)
- "Decaying Average: This method formula recognizes that the most recent score is more representative of the student’s current mastery and puts more weight on the most recent score." (https://docs.goguardian.com/products/pear-assessment/learn-how-supports-standards-based-grading.md, accessed 2026-10-24)
- "Power law: Pear Assessment interpolates the data and creates a best-fit function that is used to estimate the student’s current level of mastery based on performance and growth of the student" (https://docs.goguardian.com/products/pear-assessment/learn-how-supports-standards-based-grading.md, accessed 2026-10-24)
- "The Student Mastery Profile report provides a snapshot of student performance with standards-level performance data, links to student tests, and performance statistics per standard." (https://docs.goguardian.com/products/pear-assessment/insights-student-mastery-profile.md, accessed 2026-10-24)

- "Supported sources include state assessments (CAASPP, STAAR, PARCC, NWEA MAP, iReady, and others) as long as the data is formatted to match the required template." (https://docs.goguardian.com/products/pear-assessment/connect-external-data-sources.md, accessed 2026-10-24)
